# MiniTally Counter

MiniTally Counter is a simple, fast, and clean tally counter for iPhone and iPad. It is designed for quick counting with large buttons, clear numbers, flexible layouts, saved counters, colour themes, and optional feedback.

Use it for habits, workouts, reps, scores, inventory checks, attendance, events, knitting rows, laps, tasks, or anything else you need to count.

## Key Features

## Counter Modes

MiniTally includes several counter modes for different counting needs.

- **Single Counter**  
  A simple one-counter mode with one large plus button and reset.

- **Dual Button**  
  Count up or down with plus, minus, and reset buttons for one counter.

- **Dual Counter**  
  Use two independent counters on the same screen. Each counter has its own value, colour, plus button, and reset button.

- **Reverse Counter**  
  Start from a chosen number and count down. This is useful for countdown-style counting, limited sets, remaining items, or target-based tasks.

## Layout Options

Choose the layout that works best for your device and how you hold it.

- **Centred Big Button**  
  Places the main action in the centre for clear, focused counting.

- **Bottom Bar**  
  Places buttons at the bottom for fast access.

- **Split Screen**  
  Shows two counters clearly in Dual Counter mode.

- **Floating Buttons**  
  Keeps large buttons near thumb reach for comfortable one-handed use.

MiniTally automatically adapts layouts for iPhone and iPad.

## Number Styles

Customise how the counter number looks.

- **Large Bold**  
  High-visibility default style.

- **Thin Minimal**  
  A lighter, cleaner number style.

- **Digital**  
  Digital clock-style numbers.

- **Compact Medium**  
  A smaller balanced display for tighter layouts.

## Saved Counters

Save counters with names and review them later.

- Save the current counter value.
- Give each saved counter a name.
- View all saved counters in one list.
- Save Dual Counter values together.
- Delete saved entries when they are no longer needed.

Saved counters are useful for recording totals, session results, completed sets, scores, or repeated tracking tasks.

## Feedback Options

MiniTally includes optional feedback so every tap feels clear.

- **Haptics**  
  Physical tap feedback on supported devices.

- **Click Sounds**  
  System click sound when tapping.

- **Vibration**  
  Vibration feedback where available.

- **Voice Feedback**  
  Choose a Woman or Man voice preference.

- **Announce number every**  
  Choose Off, 5 taps, 10 taps, 12 taps, or 25 taps.

You can turn feedback options on or off from Settings.

## Themes and Colours

Personalise the app with themes and counter colours.

- Light theme
- Dark theme
- Pastel theme
- Neon theme
- Primary counter colour picker
- Second counter colour picker for Dual Counter mode

The button and number colours match for clear visual feedback.

## Reverse Counter Start Number

Reverse Counter mode includes a Start Number setting. Enter the number you want to count down from, then apply it to begin counting down.

This is useful for:
- remaining items
- countdown tasks
- target-based sessions
- limited repetitions
- score reductions
- inventory checks

## Reset and Autosave

MiniTally is built for quick use while still protecting your counters.

- Reset counters when needed.
- Optional reset confirmation.
- Autosave keeps counters and settings stored automatically.
- Counter values, settings, colours, mode, layout, and saved counters persist between launches.
